# RICH CRAFT

Статическое приложение для GitHub Pages.

## Что внутри
- Ежедневно 4 блока: **уроки / труба / помощь по дому / развитие**
- Родион сам выбирает время выполнения
- 30 тренировок блока «Развитие»
- Рост сложности от 2/5 до 5/5
- Закрытые вопросы + открытые кейсы
- Таймер развития
- Самооценка уверенности
- Учёт «уверенных ошибок»
- Недельный прогресс
- XP
- Экспорт прогресса в JSON
- PWA/service worker: после первого открытия может работать офлайн

## Быстрый запуск на GitHub Pages
1. Создать новый репозиторий, например `rich-craft`.
2. Загрузить **все файлы из этой папки в корень репозитория**.
3. GitHub → Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Через минуту GitHub покажет ссылку вида:
   `https://USERNAME.github.io/rich-craft/`

## Важно
Сейчас данные хранятся в `localStorage` браузера конкретного устройства.
То есть:
- на этом телефоне прогресс сохраняется;
- на другом устройстве автоматически не появится;
- ChatGPT сам не получает ответы в реальном времени.

Для облачной синхронизации следующий этап — добавить backend (например Supabase):
`Родион -> база -> родитель/ChatGPT -> новые задания`.

## Где менять задания
Файл `curriculum.js`.

Каждая тренировка имеет поля:
- `title`
- `skill`
- `difficulty`
- `type`: `quiz` или `open`
- `minutes`
- `intro`
- `questions` или `prompt`

## Текущая педагогическая логика
Неделя 1: контроль первого ответа  
Неделя 2: несколько условий одновременно  
Неделя 3: источники, исследование, решения  
Неделя 4: комплексные задачи и управление  
Дни 29–30: творчество и проектирование самой системы

Главное правило месяца:
**ПОНЯЛ -> ПРОВЕРИЛ -> ОТВЕТИЛ**


## Облачный журнал — уже подключён

Эта сборка пишет выполненные действия в Supabase:

- уроки;
- труба;
- помощь по дому;
- тренировки «Развитие»;
- балл и время тестов;
- уверенность;
- число уверенных ошибок;
- открытые ответы и самопроверку.

`journal_id` этой установки:

`rc_rodion_59da7a3cfbf30e70b30aa3dc`

### Как работает
Приложение сначала сохраняет всё локально, затем отправляет событие в облако.
Если интернета нет, событие остаётся в очереди и отправится при следующем подключении.

Клиент имеет право **только добавлять события**. Читать журнал из браузера нельзя.
Это специально: публичный GitHub Pages не получает права на чтение данных.

### Что это даёт
Когда в ChatGPT нужно посмотреть прогресс Родиона, можно запросить облачный журнал
и получить последние записи / статистику без копирования отчёта с телефона.

### Важно
Не публикуйте service-role ключи. В `cloud.js` используется только публичный anon-ключ,
а безопасность чтения обеспечивается RLS в Supabase.


# Защищённый облачный журнал

Эта сборка использует Supabase Edge Function:

`https://ukrgjdbhbokfkpfpqmnb.supabase.co/functions/v1/rich-craft-sync`

Репозиторий **не содержит ключ устройства**.

После публикации:
1. Открой RICH CRAFT на телефоне Родиона.
2. Нажми на строку `☁ журнал не подключён — нажми сюда`.
3. Введи выданный отдельно ключ устройства один раз.
4. После успешной проверки появится `☁ журнал подключён`.
5. Ключ хранится только в localStorage этого браузера.

Не добавляй ключ устройства в GitHub, `cloud.js`, README или issues.

Если телефон потерян, ключ можно отозвать в Supabase и выдать новый.

## Обновление GitHub
Замените файлы в репозитории содержимым архива. Папку `icons` загрузите целиком.
Адрес остаётся: https://ilya-sdi.github.io/RICH/
После обновления закройте старую вкладку и откройте сайт снова.


## Важно для GitHub с телефона
В этой сборке НЕТ папки `icons`.
Все PNG-файлы лежат в корне репозитория специально, чтобы их можно было загрузить с телефона одним списком.
После загрузки в корне должны быть:
- icon-192.png
- icon-512.png
- maskable-512.png
- apple-touch-icon.png
